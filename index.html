Veículos

Veículos fora da área operacional ou fora da base habitual dependem de bases e cercas geográficas cadastradas. A API ZUQ informa apenas o identificador da cerca nas notificações, sem o desenho da área.
Clique em um veículo para ver a linha do tempo do dia, as paradas e as viagens. Primeira e última ignição vêm do resumo diário da ZUQ; primeira e última movimentação são calculadas a partir das posições. Jornada do veículo não é jornada trabalhista do condutor: os horários de ignição não indicam, sozinhos, horário de trabalho.

Linha do tempo

Clique em uma transação para ver o posto, a posição do veículo e a distância.
Fonte dos abastecimentos: a documentação da API ZUQ recebida não tem transações de abastecimento, então elas entram por planilha (botão "Baixar modelo"). Para cada transação, o painel consulta o trajeto do veículo no dia, pega a posição mais próxima do horário e mede a distância até o posto. Resultados possíveis: compatível, fora do raio, sem posição disponível, comunicação desatualizada ou posto sem coordenadas. A precisão do GPS não é informada pela API. Divergência não é fraude: é um ponto para investigação.

Veículos por tempo sem comunicação

Sem comunicação significa ausência de dados, não veículo parado. A última localização mostrada é a última recebida, não a posição atual. "Possível falha" combina falhas de energia do resumo diário e alertas de desconexão de bateria no período carregado.

Cruzamento: pelo CPF e, quando a telemetria não traz CPF, pelo código do motorista (crachá/cartão ZUQ). Nomes parecidos nunca são usados para associar pessoas. Os condutores da telemetria vêm da API ZUQ (condutor associado agora a cada veículo e quem aparece nos eventos do período), então quem não dirigiu recentemente aparece como "sem registro recente". Privacidade: o arquivo guarda só nome, matrícula, código, status e vencimento da CNH; o CPF fica apenas como código de verificação e dígitos do meio, sem RG, data de nascimento, número da CNH ou e-mail.

Tipos de evento encontrados na API

Os eventos de condução vêm na regra "Dirigibilidade" da ZUQ. A descrição de cada evento informa o tipo, em inglês, e o painel traduz: harshBreak = frenagem brusca, fastAcceleration = aceleração brusca, sharpTurn = curva brusca. Códigos que aparecerem e ainda não tiverem tradução são mostrados como chegam da API.

Ranking de veículos por quilômetro

Pontuação por condutor = excesso moderado ×1 + elevado ×2 + crítico ×3 + dirigibilidade ×2 + marcha lenta (alerta) ×1, no período carregado. Menor pontuação é melhor. Limitação: a API não informa quilometragem por condutor (o resumo diário é por veículo), então a comparação justa por km é feita no ranking de veículos. Frenagens, acelerações e curvas bruscas entram juntas como "dirigibilidade".
Fonte: resumo diário da ZUQ no período carregado (primeira e última ignição, km e tempos). Feriados considerados: nacionais, incluindo Sexta-feira Santa; feriados estaduais e municipais não entram. Fora da região de atuação, locais não habituais e permanência longe da base dependem de bases e cercas cadastradas, que a API não fornece.

Cópia de segurança

As ocorrências ficam salvas somente neste navegador. Para várias pessoas acompanharem as mesmas tratativas é preciso um servidor com banco de dados; enquanto isso, use a cópia de segurança.

Conectar à API ZUQ

O token fica no servidor local (variável ZUQ_TOKEN). Abra esta página pelo endereço do proxy, por exemplo http://localhost:8080.

O token fica só na memória desta aba. Se a API recusar chamadas do navegador (erro de CORS ou de rede), use o proxy.
